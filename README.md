## Como os projetos são apresentados

Cada estudo de caso descreve:

- o contexto e o problema;
- a proposta de valor;
- a atuação de Maycon Bentes;
- as competências profissionais demonstradas;
- os limites de confidencialidade.

## Proteção das informações

Este repositório é exclusivamente documental. Não contém:

- código-fonte ou arquitetura interna detalhada;
- credenciais, chaves ou variáveis de ambiente;
- dados pessoais, bases de clientes ou documentos restritos;
- contratos, preços estratégicos ou regras comerciais confidenciais;
- informações que comprometam segurança ou propriedade intelectual.
